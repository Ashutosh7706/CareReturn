# Data governance

- Source: UCI Machine Learning Repository, dataset 296, Diabetes 130-US Hospitals for Years 1999–2008.
- Citation: Clore et al. (2014), DOI 10.24432/C5230J.
- Dataset license identified by UCI: CC BY 4.0. Follow its attribution requirements.
- Raw data is downloaded locally and excluded from version control.
- Never commit patient-level records or secrets.
- Review UCI's current dataset page and license before redistribution or derivative-data publication.
- Dependencies retain their own licenses; this project's source-code rights notice does not override them.
